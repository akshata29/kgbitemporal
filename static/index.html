Which entities have a current director who also holds an ownership interest — and does a rule in force require an independent director?

One multi-hop traversal across the whole corpus: Party → SERVES_AS → Entity ← HOLDS_INTEREST_IN ← same Party, then Entity → GOVERNED_BY → Jurisdiction → HAS_RULE → Axiom. Each hop is joined to kg_visible(valid, known, principals), so time and permissions are enforced at every edge, not just the endpoints.

How to read a row: at this entity, Person is a director and an owner (the two names as written in the two documents are in As extracted, with the pages in Evidence). Requires independent director means a rule in force for that jurisdiction applies to this pattern, so the entity is flagged for review; it does not check whether an independent director already exists. Pattern only means the same person is director and owner but no rule is known in force.

Entity-resolution review queue

      
Low-confidence or ambiguous resolutions are written as provisional edges and queued. Confirming a different candidate is a bitemporal correction: valid time stays the same, system time records when we fixed it, and the old assertion stays queryable "as known then".

      

    

  

  

    

      
Variable-depth paths, with time and access checked on every hop

      
Starts at any person and follows any edges for 1 to 3 hops to an entity, jurisdiction or rule. AGE can't prune a variable-length traversal by a per-hop predicate, so each path's edge ids are returned and a path is kept only if every hop passes kg_visible(valid, known, principals). Move the sliders or switch user and the set of paths changes. Cost follows the number of paths AGE produces, not the number that survive.
